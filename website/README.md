# Royal Hires — Official Public Website

This folder contains the public corporate website for **Royal Hires** and its page-transition/motion specification.

- Brand: Royal Hires
- Hero headline: Royal Hires Private Limited
- Slogan: The Royal Standard Of Recruitment
- Visual palette: near-black, deep purple, electric violet and white only — no gold.
- Static public pages/sections: Home, About, Services, Employers, Careers, Contact.
- Responsive desktop, tablet and mobile layout.
- CSS/JavaScript motion with reduced-motion support.

## Security boundary
This site is separate from the Royal Pay payroll dashboard UI. It does not connect to payroll data, employee records, salaries, attendance, invoices, payments or the existing payroll Supabase project. The contact form currently prepares a local email draft and does not store or transmit messages to a backend.

## Current state
This source is a reviewable static website prototype. It is not published. Do not deploy it through this repository's existing GitHub Pages environment without first separating the site's hosting target from the payroll app Pages deployment. A dedicated website repository or separate hosting project is preferred.
